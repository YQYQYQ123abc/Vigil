BOUNDARIES

做得到的事，
和明确不做的事。 What it does —
and what it will not do.

把边界写清楚，比「全面防护」这类说法更有用。下面每一条都和产品设计一致，不夸大能力。 Clear boundaries beat phrases like "full protection". Every line below matches how the product is actually designed.

会做It does

  • 你选的目录进入保护清单，可随时移出，文件位置不变。 Your chosen folders join the protection list, removable at any time, with files left in place.
  • 受保护的操作按实际能力拦截或记录，文案只陈述发生了什么。 Protected actions are blocked or recorded within what the system allows, described in plain factual wording.
  • 暂停保护、移出目录和修改敏感设置之前，要求先在本机完成验证。 Pausing protection, removing a folder, or changing sensitive settings requires local verification first.
  • 事件、时间与结果写入本机记录，之后可以按时间回查。 Events, times, and outcomes are written to a local record you can review later.

不会做It will not

  • 不监控整个系统：只在你选中的目录里工作。 Never monitors the whole system: it works only inside the folders you selected.
  • 不上传文件内容：没有账号依赖，也没有广告和遥测。 Never uploads file contents: no account dependency, no ads, no telemetry.
  • 不在你不知情时录屏或打开摄像头；需要时先展示范围，并在使用中持续显示状态。 Never records the screen or opens the camera without your knowledge; when needed, the scope is shown first and the state stays visible.
  • 不承诺做不到的拦截：已经打开的文件、已经进入应用内存的内容，会如实记录结果。 Never promises blocks it cannot make: for files already open or content already in an app's memory, the outcome is recorded honestly.

「拦截」指系统在操作发生前作出决定；实际覆盖范围以签名原型在真机上的测试结果为准。已打开的文件、已进入应用内存的内容，以及后台同步和外部传输，分别记录结论。 "Blocking" means the system decides before an action completes; real coverage is measured on signed builds on real hardware. Files already open, content already in memory, background sync, and external transfers are each recorded separately.

DATA

数据怎么处理。 How data is handled.

默认路径很短：留在本机，留在你自己的目录里。没有需要注册的账号，也没有需要上传的文件。 The default path is short: on this Mac, inside your own folders. There is no account to create and no file to upload.

1

只读你选的目录Reads only your folders

保护范围由你指定。系统权限按功能需要申请，缺失时页面会明确说明哪些保护暂时不可用。 You define the scope. System permissions are requested per feature; when one is missing, the app says which protection is unavailable.

2

事件与证据留在本机Records stay on this Mac

谁在什么时间做了什么、结果如何，写在本机记录里。证据的保留期限由你在设置中管理。 Who did what, when, and how it turned out goes into a local record. You decide how long evidence is kept.

存储Storage
3

不上传文件内容No file uploads

文件内容不离开这台电脑。日后接入手机提醒时，也只传事件摘要，不含文件名称和路径。 File contents never leave this Mac. When phone alerts arrive later, they will carry event summaries only — no file names or paths.
